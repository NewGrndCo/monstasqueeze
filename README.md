# Monsta Squeeze

Official retail-discovery website for Monsta Squeeze.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The site is configured for a Git-connected Netlify deployment. The shortage form uses Netlify Forms and becomes operational after the production site is connected and forms are enabled.

See `project-spec/PROJECT.md` for the implementation contract, assumptions, and production blockers.
